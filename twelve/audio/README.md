# 配乐

把音乐文件放在这个文件夹，本地运行（`play_twelve.bat` 等）时页面会自动播放；文件名决定用在哪一段：

| 文件名 | 什么时候放 |
|---|---|
| `intro.mp3` | 开场镜头 |
| `trial.mp3` | 庭审（点「开始陈词」后） |
| `reversal.mp3` | 庭审中途检方反转之后 |

也可以是 `.ogg` / `.m4a` / `.wav`。循环播放，切换时淡入淡出；标题旁的 ♪ 按钮可静音（记在浏览器里）。

这里的文件**不会进仓库**（见 `.gitignore`），所以 Render 上的线上版没有配乐。借用别人的曲子只适合自己本地玩；
要在线上放，得用自己做的或允许分发的曲子，再从 `.gitignore` 里放行。
