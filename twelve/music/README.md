# 配乐（发布版，进仓库，线上 Render 用这里的）

| 文件名 | 什么时候放 |
|---|---|
| `intro.mp3` | 开场镜头 |
| `trial.mp3` | 庭审（点「开始陈词」后） |
| `reversal.mp3` | 庭审中途检方反转之后 |
| `gavel.mp3` | 木槌声（只要一下，开庭敲两遍、闭庭敲三遍）；没有就用页面合成的声音 |

也可以是 `.ogg` / `.m4a` / `.wav`（建议 mp3，128 kbps 左右，每首几 MB 以内）。循环播放，切换时淡入淡出，标题旁 ♪ 可静音。

只放自己做的、或者允许分发的曲子。借用的曲子放 `twelve/audio/`（不进仓库，只在本地用；本地有的话优先于这里）。
